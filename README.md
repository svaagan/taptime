# TapTime – nettsiden

Personvern og hjelp for iPhone-appen TapTime, servert av GitHub Pages. Statiske filer, ingen byggsteg.

- `index.html`, `personvern/`, `support/` – norsk.
- `en/`, `en/privacy/`, `en/support/` – engelsk.
- `support/` og `personvern/` (og de engelske) er adressene i App Store Connect.
- Alle lenker er relative, så sidene virker både under `svaagan.github.io/taptime/` og på et eget domene senere.
- `fonts/` – appens fonter, Bricolage Grotesque og DM Sans, med OFL-lisensene.

Sidene lages fra én mal i appens repo, som er privat. Rett ikke HTML-filene her for hånd.
